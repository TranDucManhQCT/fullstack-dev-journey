# Git & GitHub

<details>
  <summary><b>Lịch sử phát triển</b></summary>
Năm 2005, một kỹ sư phần mềm người Phần Lan tên là Linus Torvalds gặp phải vấn đề khi xây dựng hệ điều hành Linux. Với quá nhiều phiên bản mã nguồn, việc quản lý mọi thứ trở nên vô cùng khó khăn. Vì vậy, ông đã tạo ra Git , một hệ thống kiểm soát phiên bản theo dõi các thay đổi đối với mã nguồn của dự án.

Vài năm sau, nền tảng web GitHub ra đời, được thành lập bởi Tom Preston-Werner, Chris Wanstrath và PJ Hyett tại San Francisco. Thường được gọi là "Google Drive dành cho mã nguồn", nó nhanh chóng trở thành phương thức tiêu chuẩn để các nhà phát triển lưu trữ, chia sẻ và cộng tác trên mã nguồn trực tuyến, với 150 triệu người dùng. 😱
</details>
