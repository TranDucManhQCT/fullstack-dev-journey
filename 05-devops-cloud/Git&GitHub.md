# Git & GitHub

<details>
  <summary><b>Git là gì?</b></summary>

Git là một hệ thống kiểm soát phiên bản phân tán được dùng để quản lý tiến độ của một dự án, từ đơn giản như một trang `index.html` hoặc phức tạp như một ứng dụng `full-stack` hoàn chỉnh 
- quay lại bất kỳ phiên bản nào trong lịch sử
- cộng tác với người khác làm việc song song trên nhiều tính năng.

</details>
<details>
  <summary><b>Git Bash là gì?</b></summary>

- Git Bash là một ứng dụng dành cho môi trường Windows cung cấp lớp mô phỏng cho trải nghiệm dòng lệnh Git. Windows có giao diện dòng lệnh gốc, Command Prompt, nhưng để sử dụng Bash trên Windows, chúng ta cần tải xuống và cài đặt chương trình có tên Git Bash.

- Git Bash là một gói đơn giản cài đặt Bash, một số tiện ích bash và Git trên Windows. Mục đích chính của Git Bash là cung cấp trải nghiệm Git đầu cuối.

</details>
<details>

  <summary><b>Lịch sử phát triển</b></summary>

- Năm 2005, một kỹ sư phần mềm người Phần Lan tên là Linus Torvalds gặp phải vấn đề khi xây dựng hệ điều hành Linux. Với quá nhiều phiên bản mã nguồn, việc quản lý mọi thứ trở nên vô cùng khó khăn. Vì vậy, ông đã tạo ra Git , một hệ thống kiểm soát phiên bản theo dõi các thay đổi đối với mã nguồn của dự án.

- Vài năm sau, nền tảng web GitHub ra đời, được thành lập bởi Tom Preston-Werner, Chris Wanstrath và PJ Hyett tại San Francisco. Thường được gọi là "Google Drive dành cho mã nguồn".

</details>

## Cài đặt 

Đầu tiên, hãy kiểm ra Git đã được cài đặt sẵn trên máy tình mình chưa. Tìm và mở **Terminal**, sau đó nhập lệnh:
```
git --version
```

- Nếu thấy số phiên bản `git version 2.53.0.windows.2`, thì Git đã được cài đặt.
